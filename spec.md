
* You must have an intuitive UI/UX
* Should be developed as a web application
* Should be database driven
    * You may choose any dB (preferred). You can code your own files (flat files).
    * Extra grade for hosting on cloud
* Create/Modify User Information
    * Allow users to register for accounts
    * Allow user to change account information (name etc.)
* Create/Modify Items for Sale
    * Must include images
    * Must include price
    * Must include available quantity to show ON THE MAIN SALE PAGE – not after clicking for detail.
    * Must allow ability to add new items
* Ability to search based on criteria:
    * Item/Description
    * Sort by Price
    * Sort by Availability
* Create/Modify Shopping Cart
    * Must show items in cart
    * Must calculate taxes: assume 8.25% tax rate
    * Must display discount codes and the indication about the amount being discounted,
    * Must indicate if the price is a sales price,
    * Must show summary of order and allow for order to be placed
* Administrative back end
    * Preferred with specific User interface developed for the Administrative back end
    * Allow to modify all items
    * Allow for creation of discount codes (discount information should reflect to shopping cart also))
    * Allow for creation of sales items (sales information should reflect to shopping cart also)
    * Allow to modify users
    * Show currently placed orders
    * Show history of orders
        * Sort by order date
        * Sort by customer
        * Sort by order size in dollar amount
